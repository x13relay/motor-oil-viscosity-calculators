## 1. Калькулятор смешивания масел

Онлайн-калькулятор позволяет оценить кинематическую вязкость смеси двух или трёх компонентов с известными характеристиками.

**Входные данные:**
- объём каждого компонента;
- кинематическая вязкость KV40 или KV100 каждого масла.

Пользователь вводит характеристики исходных масел и их объёмы. Калькулятор рассчитывает ориентировочную вязкость полученной смеси.

### Метод расчёта: Refutas

Для оценки вязкости смеси используется метод Refutas (Refutas Viscosity Blending Method), связанный с практикой расчёта смешения нефтепродуктов и стандартом ASTM D7152.

Вместо непосредственного усреднения кинематической вязкости используется специальная функция — Viscosity Blending Number (VBN).

Сначала для каждого компонента рассчитывается его VBN:

`VBN = 14.534 × ln(ln(ν + 0.8)) + 10.975`

где:

- `ν` — кинематическая вязкость компонента, cSt;
- `ln` — натуральный логарифм;
- `VBN` — число вязкостного смешения.

Затем определяется средневзвешенное значение VBN смеси:

`VBNсмеси = (VBN₁ × x₁ + VBN₂ × x₂ + ... + VBNₙ × xₙ)`

где `x` — доля соответствующего компонента в общем объёме смеси.

Для двух компонентов:

`x₁ = V₁ / (V₁ + V₂)`

`x₂ = V₂ / (V₁ + V₂)`

После этого полученное значение VBN преобразуется обратно в кинематическую вязкость:

`νсмеси = exp(exp((VBNсмеси - 10.975) / 14.534)) - 0.8`

Таким образом, метод позволяет оценить вязкость смеси с учётом нелинейного характера смешивания.

Калькулятор поддерживает расчёт как для двух, так и для трёх компонентов.

## 2. Обратный калькулятор смешивания

Этот инструмент решает обратную задачу: пользователь задаёт желаемую вязкость смеси и общий объём, а калькулятор определяет необходимые пропорции компонентов.

**Входные данные:**
- вязкость первого компонента;
- вязкость второго компонента;
- целевая вязкость смеси;
- общий объём смеси.

В зависимости от доступных исходных данных можно использовать дополнительные компоненты.

### Принцип расчёта

В основе лежит тот же метод Refutas.

Сначала целевая кинематическая вязкость преобразуется в VBN. Затем определяется необходимая доля каждого компонента, при которой средневзвешенное значение VBN будет соответствовать целевому.

Для двух компонентов доля первого компонента рассчитывается по формуле:

`x₁ = (VBNцель - VBN₂) / (VBN₁ - VBN₂)`

Доля второго компонента:

`x₂ = 1 - x₁`

Объёмы компонентов определяются умножением их долей на общий объём смеси:

`V₁ = x₁ × Vобщий`

`V₂ = x₂ × Vобщий`

Результат позволяет понять, в каких пропорциях необходимо смешать исходные масла для получения расчётной вязкости.

Важно: целевая вязкость должна находиться между вязкостями исходных компонентов, если требуется получить смесь только из этих компонентов.

## 3. Калькулятор индекса вязкости

Индекс вязкости (Viscosity Index, VI) — безразмерная характеристика, которая показывает, насколько сильно изменяется кинематическая вязкость масла при изменении температуры.

Чем выше VI, тем меньше относительное изменение вязкости при изменении температуры в рассматриваемом диапазоне.

Калькулятор использует два значения:

- KV40 — кинематическая вязкость при 40 °C;
- KV100 — кинематическая вязкость при 100 °C.

### Метод расчёта: ASTM D2270

Индекс вязкости определяется по методике ASTM D2270.

Стандарт сравнивает исследуемое масло с условными эталонными маслами, имеющими одинаковую вязкость при 100 °C, но разные характеристики изменения вязкости с температурой.

Для расчёта используются следующие величины:

- `U` — фактическая кинематическая вязкость исследуемого масла при 40 °C;
- `Y` — кинематическая вязкость исследуемого масла при 100 °C;
- `L` — вязкость при 40 °C эталонного масла с VI = 0;
- `H` — вязкость при 40 °C эталонного масла с VI = 100.

Для масел с индексом вязкости до 100 используется формула:

`VI = ((L - U) / (L - H)) × 100`

Для масел с индексом вязкости выше 100 применяется дополнительная расчётная зависимость, предусмотренная ASTM D2270.

В ней используются логарифмические соотношения, позволяющие определить индекс вязкости для масел, характеристики которых выходят за пределы эталона VI = 100.

### График вязкости в зависимости от температуры

В калькулятор также встроен интерактивный график зависимости кинематической вязкости от температуры.

Для построения кривой используется уравнение Вальтера (Walther equation), применяемое в методике ASTM D341.

В общем виде зависимость описывается выражением:

`log10(log10(ν + 0.7)) = A - B × log10(T)`

где:

- `ν` — кинематическая вязкость, cSt;
- `T` — абсолютная температура в Кельвинах;
- `A` и `B` — расчётные коэффициенты.

Коэффициенты определяются по двум известным значениям вязкости — KV40 и KV100.

На основании этих данных строится расчётная кривая изменения вязкости при различных температурах.

График помогает наглядно оценить, как меняется вязкость масла при нагревании и охлаждении.

Важно понимать, что расчёт по уравнению Вальтера не заменяет низкотемпературные лабораторные испытания CCS и MRV.

## 4. Калькулятор примерной вязкости смеси по SAE

Этот инструмент предназначен для предварительной оценки возможной кинематической вязкости смеси моторных масел, если известны только их классы вязкости SAE.

**Входные данные:**
- класс SAE первого масла, например 5W-30;
- объём первого компонента;
- класс SAE второго масла, например 5W-40;
- объём второго компонента;
- при необходимости — третий компонент.

В отличие от обычного калькулятора смешивания, здесь не требуется знать точные значения KV40 или KV100 исходных масел.

### Принцип расчёта

Калькулятор использует ориентировочные диапазоны кинематической вязкости при 100 °C, соответствующие высокотемпературным классам SAE.

Для примера:

- SAE 20 — от 5.6 до менее 9.3 cSt;
- SAE 30 — от 9.3 до менее 12.5 cSt;
- SAE 40 — от 12.5 до менее 16.3 cSt;
- SAE 50 — от 16.3 до менее 21.9 cSt;
- SAE 60 — от 21.9 до менее 26.1 cSt.

Для каждого выбранного класса формируется ориентировочный диапазон возможной вязкости.

Далее оценивается возможный диапазон вязкости смеси с учётом объёмных пропорций компонентов.

Результат показывает приблизительные границы KV100, в которых может находиться полученная смесь.

### Для чего нужен этот калькулятор

Например, пользователь хочет смешать некоторое количество масла 5W-30 и 5W-40, но не располагает точными лабораторными значениями KV100.

Вместо выбора произвольного значения калькулятор позволяет получить приблизительный диапазон вязкости смеси на основании классов SAE.

Это предварительная оценка, а не точный лабораторный расчёт.

## Ограничения расчётов

Калькуляторы позволяют оценить вязкость моторных масел и смесей на основе известных характеристик и математических моделей. Полученные результаты помогают проводить предварительные расчёты, сравнивать масла и подбирать пропорции компонентов.

При использовании инструментов стоит учитывать несколько особенностей:

- Расчётная вязкость может отличаться от фактической. Методы Refutas и Вальтера позволяют получить хорошую предварительную оценку,однако реальные характеристики смеси зависят от состава масел и их свойств.

- Вязкость — лишь одна из характеристик моторного масла. Одинаковая или близкая вязкость не означает, что масла полностью совместимы или обладают одинаковыми эксплуатационными свойствами. Для оценки соответствия требованиям SAE и автопроизводителей необходимо учитывать и другие характеристики.

- Расчётные значения не заменяют лабораторные испытания. Особенно это касается низкотемпературных свойств масла, которые определяются отдельными методами, например CCS и MRV.

Калькуляторы предназначены для технических оценок, сравнения характеристик и экспериментов с вязкостью. Они помогают лучше понять свойства масел и влияние смешивания компонентов на итоговую вязкость.

## Когда могут пригодиться калькуляторы моторного масла

Калькуляторы вязкости могут быть полезны когда возникает необходимость смешивания различных смазочных материалов.

### 1. Использование остатков масел после предыдущих замен

После нескольких замен масла в гараже могут оставаться частично использованные канистры с разными вязкостями: например, 0W-20, 5W-30 или 5W-40.

Можно смешать остатки масел и предварительно рассчитать примерную вязкость полученной смеси.

Это может пригодиться для подготовки смеси масел для полноценной замены или для для технической промывки мотора непосредственно перед заменой. Расчёт помогает понять, как изменится вязкость смеси в зависимости от пропорций компонентов.



### 2. Добавление присадок в моторное масло

Некоторые присадки добавляются непосредственно в моторное масло и могут влиять на его итоговую вязкость.

Если известны объём добавляемого продукта и его кинематическая вязкость, калькулятор смешивания позволяет предварительно оценить изменение KV40 или KV100 полученной смеси.

Это может быть полезно для понимания того, насколько заметно добавление определённого объёма продукта изменит общую вязкость масла.

### 3. Эксперименты со смешиванием масел

Калькуляторы также подходят для самостоятельных экспериментов и изучения свойств различных моторных масел.

Можно проверить:
- как изменяется вязкость при смешивании масел разных классов SAE;
- как соотношение компонентов влияет на итоговую KV40 и KV100;
- какие пропорции необходимы для получения заданной расчётной вязкости;
- как изменяется индекс вязкости при изменении характеристик исходного масла;
- как будет выглядеть расчётная зависимость вязкости от температуры.

Это удобный способ изучать физические свойства смазочных материалов, проверять различные гипотезы и проводить предварительные расчёты до реальных экспериментов.

**Важно:** калькуляторы предназначены для оценки вязкости, а не для подтверждения безопасности смешивания. Получение желаемой вязкости не означает, что смесь соответствует допускам автопроизводителей или подходит для конкретного двигателя.
